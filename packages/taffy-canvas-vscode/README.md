# `taffy-canvas-preview`

Local VS Code extension for live Taffy Canvas template preview.

Recommended template file name pattern: `*.taffy.xml`

Current behavior:

- registers `*.taffy.xml` with VS Code's built-in `xml` language mode
- installs Red Hat XML as a dependency and associates `*.taffy.xml` with the bundled XSD schema
- adds an editor-title preview button for `*.taffy.xml`
- previews the active XML document by showing the PNG generated by the wasm renderer
- reloads automatically while editing
- reads root-level `<preview>` presets from the XML file and lets you switch between them
- merges the selected preset over `taffyCanvas.preview.params`
- auto-detects `resources.json` or `taffy.resources.json` next to the template, or uses `taffyCanvas.preview.resourceManifest`

The packaged extension vendors the sibling `taffy-canvas-web` runtime into its own `web/` folder before packaging.

Prepare the extension runtime:

```bash
npm --workspace packages/taffy-canvas-vscode run prepare:runtime
```

Build a self-contained VSIX:

```bash
npm --workspace packages/taffy-canvas-vscode run package:vsix
```

Package and install locally:

```bash
npm --workspace packages/taffy-canvas-vscode run install:local
```

`package:vsix` stages a minimal extension payload under `.build/` before invoking `vsce`, which avoids packaging the rest of the monorepo.
