# Examples

These example templates use the recommended `*.taffy.xml` naming pattern.

- [hello-card.taffy.xml](/Users/dj/.codex/worktrees/5273/taffy-canvas/examples/hello-card.taffy.xml): minimal card with two root-level preview presets
- [status-strip.taffy.xml](/Users/dj/.codex/worktrees/5273/taffy-canvas/examples/status-strip.taffy.xml): flex layout with stat presets for different players
- [dashboard-grid.taffy.xml](/Users/dj/.codex/worktrees/5273/taffy-canvas/examples/dashboard-grid.taffy.xml): grid layout with switchable mission presets

All three files avoid external assets so they can be compiled immediately, and each shows the root-level `<preview>` metadata format used by the VS Code extension.
